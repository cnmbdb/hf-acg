# Mintlify 文档发布指南

本项目已经把文章管理、GitHub 和 Mintlify 串联起来。管理员只需要在后台维护内容，系统会完成文档生成和线上部署。

## 发布流程

1. 在后台“文章列表”中新建文章。
2. 填写标题、Slug、摘要、标签和正文。
3. 保存草稿并确认内容无误。
4. 点击“发布”，系统生成 MDX 文件并提交到 GitHub。
5. Mintlify 检测到仓库更新后自动构建站点。

## 发布后会更新什么

每次发布文章时，系统会同时更新：

- 文章详情页 `/blog/{slug}`
- 博客首页 `/`
- 文章目录 `/blog`

## 注意事项

Slug 只能使用小写字母、数字和连字符。正文支持 Markdown 和 Mintlify MDX 组件，但不需要手工添加 frontmatter，系统会自动生成。
