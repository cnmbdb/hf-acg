# 一、CRM系统是什么？

CRM（Customer Relationship Management）即客户关系管理系统。

它主要用于：

* 保存客户信息
* 管理销售流程
* 记录客户沟通
* 提醒销售跟进
* 分析客户数据

简单来说：

Facebook负责找到客户。

CRM负责管理客户。

销售负责转化客户。

三者结合，可以形成完整的客户开发体系。
