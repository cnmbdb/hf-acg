## 一、什么是2FA验证码？

2FA是“Two-Factor Authentication”的缩写，中文通常称为：

- 双重身份验证
- 两步验证
- 二次验证
- 双因素认证

普通账号登录一般只需要输入账号和密码。

开启2FA双重验证以后，除了账号密码之外，系统还会要求用户输入一个动态验证码，用于确认当前登录操作确实由账号本人完成。

一个常见的2FA登录流程如下：

1. 输入账号、手机号或邮箱
2. 输入账号登录密码
3. 平台要求进行双重身份验证
4. 通过身份验证器生成6位动态验证码
5. 将验证码输入登录页面
6. 验证成功后进入账号

因此，即使账号和密码填写正确，如果没有正确的2FA验证码，也可能无法完成登录。

## 二、什么是2FA密钥？

2FA密钥是一串用于生成动态验证码的字符。

它通常由大写英文字母和数字组成，例如：

```text
JBSWY3DPEHPK3PXP

需要特别注意：

2FA密钥并不是直接填写到Facebook登录页面中的6位验证码。

2FA密钥的作用，是交给身份验证器计算并生成动态验证码。

简单理解就是：

2FA密钥 → 身份验证器 → 生成6位动态验证码

真正填写到登录页面中的，是身份验证器生成的6位数字。

例如：

284916

以上数字仅作为格式示例，实际登录时应使用工具当前生成的验证码。

三、2FA密钥和6位验证码有什么区别？

很多用户登录失败，是因为把2FA密钥和动态验证码弄混了。

2FA密钥

2FA密钥通常具有以下特点：

由英文字母和数字组成
字符数量通常比较长
用于生成验证码
不会每30秒自动改变
应妥善保管，不能随意泄露

示例：

JBSWY3DPEHPK3PXP
6位动态验证码

动态验证码通常具有以下特点：

一般由6位数字组成
具有有效时间
会定时自动更新
用于填写到平台的验证页面
过期后需要重新生成

示例：

284916

所以，正确的操作方式不是把2FA密钥直接输入Facebook，而是先使用2FA密钥生成6位动态验证码，再把验证码填写到Facebook登录页面。

五、获取2FA验证码前需要准备什么？

在开始操作前，请准备以下内容：

正确的账号或邮箱
正确的账号登录密码

最重要的是确认：

当前2FA密钥必须与正在登录的账号一致。

如果使用了其他账号的2FA密钥，即使成功生成了6位验证码，也无法通过当前账号的验证。

十一、为什么生成了验证码却无法登录？

如果验证码已经成功生成，但平台仍然提示错误，可以按照下面的方法排查。

1. 2FA密钥与账号不匹配

这是最常见的原因。

每个账号通常都有独立的2FA密钥。如果登录A账号，却使用了B账号的2FA密钥，生成的验证码一定无法通过验证。

核对账号名称
