# 一、Facebook Pixel是什么？

Facebook Pixel（现在称为Meta Pixel）是一段安装在企业网站中的代码。

它可以帮助企业记录：

用户从Facebook广告进入网站后发生了什么。

例如：

用户点击广告

↓

进入网站

↓

浏览产品页面

↓

填写咨询表单

↓

提交联系方式

这些行为都会被Pixel记录。

---

简单理解：

Facebook广告负责带来客户。

Pixel负责观察客户行为。

数据帮助广告系统找到更精准的人。

---

对于B2B企业来说，Pixel可以帮助了解：

* 哪些客户访问网站
* 哪些页面最受关注
* 哪些广告带来询盘
* 哪些用户可能再次转化
